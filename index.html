Umbral de los Tres Dados

Una mazmorra táctica de una sola carta. Asigna tres dados, abre camino entre criaturas y aguanta hasta el último umbral.

Preparación

Elige a tu aventurero

Cada clase altera tu margen de error. Escoge una ventaja y decide cuándo gastar tu talento de nivel.

Clases

Primero selecciona una clase. Después puedes continuar una partida guardada o empezar una nueva expedición.

Siguiente paso

Continúa una expedición guardada o entra de nuevo al umbral desde el primer nivel.

1. Asigna energía

Lanza tres dados y arrástralos o tócalos para asignarlos a Movimiento, Ataque y Defensa. El valor del dado se suma al atributo base durante el turno.

MovimientoPuntos para moverte.
AtaquePuntos para herir enemigos.
DefensaAbsorbe daño del turno.
AlcanceDistancia máxima de ataque.

2. Muévete y ataca

Arrastra al héroe o toca las casillas verdes. Los enemigos atacables se marcan en rojo y puedes pulsar su casilla para atacar. Mientras tengas puntos puedes combinar varios movimientos y ataques.

3. Resiste la fase enemiga

Al terminar tu fase, los monstruos se recolocan y atacan. Cuando limpies un nivel, podrás curarte o mejorar un atributo permanente.
